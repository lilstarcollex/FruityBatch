# Проверка FL Pack 1.2.2

17 октября 2026, Windows x64.

## Разбор журналов D:\Music

В `.flpack` обнаружены 358 журналов: 314 завершённых проектов и 44 проекта с последней сохранённой ошибкой. Это состояние журналов, а не полная история всех попыток.

| Последняя ошибка | Проектов | Исправление |
| --- | ---: | --- |
| Изменение состава исходной папки | 32 | Учитываются создаваемые FL временные `.zip~` и файлы анализа `.wav.zpa` |
| Изменение существующего `.wav.zpa` | 2 | Обновление файла анализа допускается при неизменном исходном WAV |
| Таймаут FL Studio | 9 | Лимит увеличен с 20 до 120 секунд; при таймауте сохраняются последние наблюдения об окнах |
| EPERM при переименовании `t line mix` в карантин | 1 | Повторные попытки при EPERM/EACCES/EBUSY: суммарная задержка до 3 секунд |

Проверка текущих исходников по исправленным правилам прошла для всех 43 журналов в состояниях exporting/exported. Исходные папки, ZIP и журналы D:\Music не изменялись. Экспорт этих 43 проектов повторно не запускался: проверка исходников не гарантирует завершение экспорта за новый лимит. Постоянная блокировка доступа также может потребовать закрытия удерживающего папку приложения.

Дополнительное сканирование нашло 70 оставшихся папок проектов, включая 23 папки с несколькими FLP в корне. Для них нужно определить основной FLP; автоматический выбор не выполняется.

Подробные ошибки и результаты проверки: `test-results/music-audit-1.2.2.json`.

## Изменения и защита исходников

Обработка артефактов применяется только до проверки и публикации ZIP. Допускается изменение `.wav.zpa` только при наличии соответствующего WAV в исходной описи. Исключение для точного имени `<основной FLP>.zip~` применяется, только если файл отсутствовал в исходной описи. Предсуществующий файл с таким именем остаётся защищённым.

FLP, WAV и остальные файлы сохраняют проверки целостности. После экспорта опись обновляется для служебных артефактов; перед удалением полная опись проверяется по содержимому, после перемещения в карантин — повторно по метаданным. Штатный ZIP не пересобирается и не изменяется.

Предупреждения и ссылки на снимки диалогов теперь сохраняются в журнал при ошибке экспорта, а не только при успешном завершении.

## Проверки

- 19 Node-тестов: существующие проверки целостности, восстановление exporting/exported с артефактами FL, побайтная неизменность ZIP, запрет изменений аудио/FLP/посторонних файлов, повторная попытка при блокировке.
- 7 Python-тестов: настоящие Win32-диалоги, последовательность диалогов, чужие процессы, таймаут, зависший обработчик окон.
- TypeScript и production build прошли.
- UI-тест прошёл.
- Реальный экспорт двух тестовых копий прошёл: один проект без замечаний, второй с подтверждённым предупреждением об отсутствующем плагине. SHA-256 опубликованных ZIP совпали со штатными ZIP FL Studio. Общая длительность — 36,873 секунды.
- Полный цикл собранного Electron-приложения со встроенным Python также прошёл на двух свежих тестовых копиях. Отчёт: `test-results/packaged-2026-10-17T12-46-15-643Z/report.json`.
- Backend и UI в app.asar совпали с исходниками и production build; версия сборки — 1.2.2. Встроенный экспортёр совпал с результатом PyInstaller.

Сборка: `release/FL-Pack-1.2.2-Windows.exe`. Для применения обновления закройте старое окно FL Pack и запустите новую сборку.
