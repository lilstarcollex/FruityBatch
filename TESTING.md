# Проверка FL Pack 1.2.0

17 октября 2026, Windows 11 x64. Исторический отчёт старой логики сохранён в TESTING-1.1.md; его требования к пересборке отменены.

## Проверяемый контракт

Штатный `/Z` FL Studio создаёт ZIP. Продукт только читает его для проверки, публикует без изменения байтов и затем удаляет папку проекта. Бэкапы и неиспользуемые файлы не добавляются, экспортированный FLP не заменяется.

## Автоматические проверки

14 Node-тестов проходят: побайтовая идентичность исходного штатного ZIP и результата, сохранение экспортированного FLP при его отличии от исходника, исключение бэкапов/лишних файлов, CRC/повреждения/невалидный FLP, блокировка неоднозначного ZIP и результатов старой пересборки, подмена архива после проверки, изменение исходников, конфликт результата, остановка, восстановление удаления после сбоя, запрет удаления по журналам старой версии, точная ошибка экспортёра в журнале.

4 Python-теста диалогов проходят. UI-тест проходит: чёрный фон, выбор папки, поиск, окно запуска, детали проекта, отсутствие sidebar и ошибок renderer. TypeScript и production build проходят.

## Сборка

`release/FL-Pack-1.2.0-Windows.exe`. Байты backend/UI в app.asar и бинарник экспортёра сверены с текущими исходниками/сборкой helper. В runtime нет yazl или ffmpeg-static.

CRC и контейнер FLP проверяют целостность, а не музыкальную эквивалентность и не доступность плагинов. Утилита сохраняет результат FL Studio ровно таким, каким его сформировала FL Studio. Папка после проверки удаляется целиком; файлы, которые штатный экспорт не включил, отдельно не сохраняются.
