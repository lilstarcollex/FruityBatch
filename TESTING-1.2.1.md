# Проверка FL Pack 1.2.1

17 октября 2026, Windows 11 x64.

Блокирующие окна штатного экспортёра и дочерних процессов подтверждаются или закрываются без переключения фокуса. Поддерживаются стандартные кнопки и сообщения мыши для Delphi-контролов. Непринятое нажатие повторяется. Ошибка отдельного окна не прерывает просмотр остальных. Закрытые диалоги записываются в предупреждения проекта.

Таймаут штатного экспорта — 20 секунд с запуска процесса; подготовка и проверка ZIP в этот срок не входят. Независимый поток завершает собственный процесс FL и экспортёр даже при зависании опроса окон. При ошибке исходники сохраняются, очередь продолжает обработку следующих проектов.

Проверено:

- 14 Node-тестов обработки архивов прошли.
- 7 Python-тестов прошли: распознавание missing-plugin, настоящий Win32 missing-plugin, обычный OK, три последовательных диалога, чужое окно, значение таймаута, завершение собственного процесса по таймауту. Последняя проверка выполнена и с зависшим обработчиком окон.
- UI-тест и production build прошли.
- Встроенный в сборку EXE экспортёр на отдельном тестовом процессе закрыл три настоящих Windows-диалога подряд и сообщил об успешном завершении.
- Backend и файлы UI в app.asar побайтно совпали с исходниками/production build; версия package.json — 1.2.1. Бинарник экспортёра в resources совпал с результатом PyInstaller.

Полный реальный экспорт FL Studio в этой проверке не запускался: уже открытый пользовательский процесс FL64 оставлен нетронутым. Проверки не гарантируют закрытие каждого возможного нестандартного окна стороннего плагина; для оставшихся блокировок действует таймаут.

Сборка: `release/FL-Pack-1.2.1-Windows.exe`.
